# review_checklist.md — 納品前チェックリスト（PPTX）

> 完成物（`outputs/` の PPTX）を PR レビュー・ユーザー確認に出す前に、必ず全項目を確認する。
> 社外提出物になり得るものとして、品質基準は常に高く保つ。
> 体裁の具体値（フォント・サイズ・配色・固有要素）は `agent_docs/project/format_rules.md` が正。
> **プロジェクト固有の必須要素があれば、この項目に追記して使う。**

## 1. 内容（骨子との一致 = テスト緑に相当）

- [ ] spec.md（骨子）のスライド一覧と過不足なく一致しているか
- [ ] 各スライドのタイトルが内容と合っているか
- [ ] 数値・型番・固有名詞が data_sources.md の元データと一致するか（推測値が無いか）
- [ ] 単位・桁・有効数字・日付が正しいか
- [ ] 誤字脱字・変換ミスが無いか
- [ ] 文体が統一されているか（敬体/常体は format_rules.md の指定どおり）

## 2. 体裁（format_rules.md 準拠 = lint に相当)

- [ ] フォントがテンプレート指定のものか、勝手に変えていないか
- [ ] 文字サイズ・太字の階層が format_rules.md どおりか
- [ ] 配色が format_rules.md どおりか
- [ ] テンプレート固有の必須要素（まとめ帯・ロゴ・区切り線など）が全対象スライドにあるか
- [ ] ページ番号が入っているか
- [ ] 社名・組織名の表記が統一されているか
- [ ] テンプレートに無い装飾（不要なアクセント線・飾り帯）を足していないか

## 3. レイアウト（画像化して通し見）

- [ ] テキストのはみ出し・見切れが無いか
- [ ] 要素の重なり・極端な余白の偏りが無いか
- [ ] 図・グラフが鮮明で、キャプション/出典があるか
- [ ] スライドの順序・ページ番号の通し順が正しいか

## 4. ファイル

- [ ] `templates/フォーマット.pptx` を直接編集していないか（編集したのは outputs のコピーか）
- [ ] ファイル名が命名規約（format_rules.md / plan.md の指定）どおりか
- [ ] 余分な作業用スライド・コメント・スピーカーノートが残っていないか
- [ ] ファイルが破損なく開けるか（python-pptx で再読込 or PowerPoint で開く）

## 5. 引き継ぎ

- [ ] progress.md の「対象ファイル（最新・唯一の正）」を更新したか
- [ ] ユーザーに、変更点・判断した点・確認してほしい点を添えて報告したか
